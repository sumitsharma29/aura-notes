## 📖 Overview

**Aura Notes** is not just another note-taking application; it is an extraordinary, feature-rich workspace designed for those who value both aesthetics and functionality. With a gorgeous dark-themed UI, an intuitive rich-text editor, and powerful export capabilities, Aura Notes brings the functionality of native desktop apps right into your browser.

---

## ✨ Features

- 🎨 **Stunning Aesthetics**: Premium dark theme by default with beautiful glowing accents and smooth micro-animations.
- ⚡ **Slash Commands**: Just press `/` to instantly insert Headers, Lists, Quotes, or Code Blocks.
- ✍️ **Rich Text Editing**: Full formatting capabilities (Bold, Italic, Code, Highlights, Color picker, and more!).
- 🖼️ **Media Support**: Seamlessly embed web links and inline images directly into your notes.
- 🗂️ **Typography Control**: Choose between carefully selected fonts (*Outfit, Inter, Merriweather, Fira Code*).
- 💾 **Auto-Save & Deep Search**: Never lose a thought. Everything saves to your local device automatically, and a powerful search bar lets you find notes instantly.
- 🎯 **Focus Mode**: Hide distractions and immerse yourself deeply in writing.
- 📌 **Pin Notes**: Keep your most important ideas always at the top.
- 📤 **Export Everywhere**: Export your notes to **TXT, Markdown, or HTML**, and utilize premium **PDF & PNG** exports.
- 📏 **Word & Read Time Metrics**: Live tracking of word count, character count, and estimated reading time.

## 🚀 Quick Start

Aura Notes is built using pure Vanilla web technologies, making it incredibly lightweight and fast. Zero build steps required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sumitsharma29/aura-notes.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd aura-notes
   ```
3. **Run the app:**
   Simply open `index.html` in your favorite modern browser. Alternatively, use a local server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code to avoid CORS issues if loading ES modules.

## ⌨️ Slash Commands & Shortcuts

Aura Notes was built for power users.

| Trigger | Action |
| --- | --- |
| `/` | Open the Slash Command menu (Headers, Lists, Quotes, Code) |
| `Ctrl + N` | Create a New Note |
| `Ctrl + B` | **Bold** text |
| `Ctrl + I` | *Italic* text |
| `Ctrl + U` | <u>Underline</u> text |

## 🏗️ Technical Stack

- **HTML5**: Semantic web structure.
- **CSS3 / Vanilla CSS**: Stunning animations, shapes, glassmorphism, and responsive design without heavy frameworks. 
- **Vanilla JavaScript (ES6+)**: Fast, responsive application logic, dynamic DOM manipulation, and local storage integration.
- **External Libraries**:
  - `html2pdf.js` & `html2canvas.js` for seamless file exporting.
